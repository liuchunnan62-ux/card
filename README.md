# 裂隙征途

原生 HTML/CSS/JavaScript 制作的单机卡牌闯关冒险 MVP，无后端、无构建步骤、无网络依赖。

## 启动

- 直接双击 `index.html`；或
- 右键使用 PowerShell 运行 `start-game.ps1`。

如果浏览器对 `file://` 页面的本地存储有限制，可运行 `start-server.ps1`。它会启动项目自带的轻量静态服务器并打开 `http://127.0.0.1:8765/`，无需安装 Node.js 或 Python；按 `Ctrl+C` 停止。

存档保存在当前浏览器的 `localStorage`。建议持续使用同一个浏览器打开游戏。

## 英雄与存档

- 封面“新游戏”会进入选人界面：除罗兰·维克（前王都护卫队长：野兽陆续觉醒后，他离开王都、集结自己的小队奔赴各地平乱）外还有8名可选英雄，每人拥有独特的英雄技能（开局自动装备，同样最高3级，可在竞技场培养）。
  - 莉瑟尔「穿林箭」：无视前排保护打击任意敌方随从，击杀后抽牌。
  - 薇奥菈「奥术飞弹」：随机分配多枚1点伤害的飞弹。
  - 赛琳娜「晨曦复苏」：己方随从恢复满生命并治疗英雄。
  - 格罗姆「血怒狂击」：失去生命，让一个随从增攻并立即再次攻击。
  - 埃尔德「林间伏兵」：在后排召唤可立即攻击的远程弓手。
  - 瑟拉「猩红连刃」：打击敌方前排随从，击杀后返还法力并可在本回合再次使用。
  - 奥斯坦「圣盾壁垒」：加固整条前排；前排为空时召唤圣盾卫士。
  - 希尔瓦「萌芽古树」：召唤每回合成长+1/+1的古树幼苗。
- 魅魔、狼人与吸血鬼（原图第6、8、12张）是需要达成成就才能解锁的英雄，目前只展示头像，暂无内容。
- 共15个存档栏位。新游戏时选择栏位；之后的进度会自动保存到当前栏位。主菜单“存档”可读取、另存到其他栏位或删除；封面“读取存档”可切换到任意栏位。
- 旧版的单一存档会在首次打开时自动迁移到1号栏位。

## 操作

- 点击手牌，再点击合法空格或目标。
- 点击带绿色边框的己方随从，攻击箭头会指向鼠标或合法目标；再点击高亮的敌人或敌方英雄。
- 近战攻击随从时会承受反击；远程攻击随从时不会受到反击。
- 前排会保护同列后排；同列前后排都为空时，路线被突破。
- 世界地图下方海港可进入七关“统领试炼”；每关首次通关永久增加1点最大法力。
- 第一关第一个首领会掉落“含有女王血液的河水”，用于开启第七场女王低语试炼。
- 法力碎片已经取消，冒险战利品、事件与商店不再出售或掉落永久法力。
- 战斗中点击我方英雄头像可打开表情菜单（问候、称赞、感谢、惊叹、抱歉、嘲讽），我方台词按所选英雄各不相同（9名英雄各有一套），对面则一视同仁地把他们当作人类一方来回应：各章守卫以族群口吻作答，狼王、翠影女王、丰穗战母、碧露大贤者、银灰狼女猎手、魅魔军官与伊瑟兰妲各有专属台词。表情有2.5秒冷却。
- 背景音乐：主界面（含地图、商店等非战斗界面）、冒险战斗、竞技场战斗与统领试炼各有一首原创程序化配乐，由 `js/music.js` 用 Web Audio 实时合成，不需要音频文件；切换界面时自动淡入淡出，战斗结束时淡出以便听清胜负音效。浏览器要求先点击一次页面才会开始播放。“设置”页可单独开关音乐和调节音乐音量。
- 操作音效：除战斗音效外，击败首领、关卡通关、竞技场获胜/夺冠、统领试炼通关与法力提升、英雄升级、卡牌升级与训练、救治伤员、商店购买、领取奖励、卡组增删、装备技能、存读档、回合开始/结束、选牌、表情以及普通按钮点击都有各自的程序化音效；操作被拒绝时会发出提示音。
- 金杯餐馆与首领好感度：城镇商店的金杯餐馆已开业，出售麦香面包、炭烤肉串、金蜜松饼、月露果冻、炙烤带骨肉、猎人炖锅、丰收宴席等食物（买到的食物放进背包）。第二关起每个普通/精英首领的首杀奖励卡，都要去营地监狱探望对应的在押首领，投喂食物把好感度提升到100、与其结缘后才能编入卡组出战；未结缘的卡即使已在卡组里也不会出战。哥布林最爱炭烤肉串、熊族最爱金蜜松饼、史莱姆最爱月露果冻、狼族最爱炙烤带骨肉，投喂最爱的食物好感翻倍。好感度100为结缘（Lv1，只是解锁），之后每100点升一级，最高500点“誓约 Lv5”；结缘后每高一级，随从卡+1攻击、+10生命，法术卡效果相当于提升2级（伤害、治疗、召唤等数值随之提高），加成只作用于玩家自己的卡牌。各关最终首领被同族救走、不在监狱中：它的卡牌要等本关19名在押首领全部结缘才能使用，好感等级取其中最低的一位，所以要全部升级它才会升级。
- 队伍粮食：顶栏显示现有粮食与每场战斗的消耗（类似魔兽争霸的人口食物）。每场冒险或竞技场战斗开战时，按“能出战的随从牌数 + 营地监狱在押犯人数”扣除粮食，随从和犯人越多消耗越大。粮食用金杯餐馆的面粉补充（2金币一袋 = 5份粮食，可一次买10袋、50袋）。开战时粮食不够，可以一键买够面粉出战，也可以饿着肚子出战（剩余粮食吃光，本场我方随从攻击-1）。新存档自带60份粮食。
- 游戏时间：顶栏显示“第N天 时:分”，现实24分钟为游戏里的一天（封面、选人、读档界面不计时，页面切到后台时暂停；存档各自记录天数）。每名在押首领每天只能投喂一次；每到新的一天，队伍额外吃掉3场战斗的口粮（出战随从 + 在押犯人，×3），库存不够时吃光并提示去买面粉。城镇的赤龙客栈已开业：花30金币睡一晚，直接跳到第二天早上6:00，口粮照常按一天消耗，投喂次数也会刷新。
- 犯人派遣劳动：营地监狱中已结缘的首领每天可以派出去干一次活（监狱页可一键派遣），游戏时间6小时（现实6分钟）后自动回营交出收获，干活期间不能投喂。哥布林下矿带回金币（结缘Lv1 10金币 → 誓约Lv5 30金币）；熊族种田产面粉补充粮食（8 → 24份）；史莱姆熬药给卡组里随机一张未满级卡牌加经验（1 → 5点）；狼族打猎带回粮食与炙烤带骨肉（2份粮食+1份肉 → 10份粮食+2份肉）。
- 好感剧情（`js/bond-stories.js`）：探望在押首领时，它会按种族与当前好感等级说一句心声；好感达到挚友 Lv3 时解锁它自己的个人往事（76名首领各一段）。监狱页“📖 族群往事”收录哥布林、熊族、史莱姆、狼族各5章本族往事，按本关全部在押首领的好感等级总和（1/10/25/50/95）逐章解锁，最终章需全部誓约。投喂解锁新剧情时会有提示。
- 夜晚事件（`js/night-events.js`）：游戏里每晚22:00入夜（顶栏时钟变为🌙），典狱长艾德琳会报告一件监狱里的事，每晚最多一件，有的需要做选择；战斗中发生的事件会等回到普通界面再报告，在赤龙客栈过夜可以跳过当晚事件。粮食吃光时必定“牢里闹起来了”（花钱连夜补粮，或所有在押首领好感-10，已结缘的不会跌回未结缘）；其余随机：越狱企图（好感低于30的首领撬锁：20金币换锁，或去谈谈好感+8、粮食-5）、深夜礼物（挚友以上的首领按种族送金币/粮食/卡牌经验/带骨肉）、牢房夜话（同族两名已结缘首领好感各+5）、粮仓鼠患（10金币买捕鼠夹，或交给典狱长的猫：一半机会损失一成粮食）；每7天一次月圆之夜，狼族首领好感各+5。夜晚事件带来的好感变化不占用当天的投喂次数。
- 按 `F2` 显示或隐藏开发者调试面板。

## 多语言

支持简体中文、繁体中文、English、日本語、한국어、Español、Português、Français、Deutsch、Русский。其中西班牙语、葡萄牙语、法语、德语、俄语由英文版机器翻译（Claude Haiku）而来，可能有不够地道的地方。首次打开时按浏览器语言自动选择，之后可在封面右上角或“设置”页切换，选择会保存在浏览器中。

- 游戏代码照常写简体中文，`js/i18n.js` 会在文字显示前替换成所选语言。
- 每种语言的译文在 `js/i18n/<语言代码>.js`：键是简体中文原文，值是译文；原文里的 `{0}`、`{value}` 等是变量，译文可以调整它们的位置。
- 新增或修改中文文本后，繁体中文会自动逐字转换兜底；其他语言需要在对应文件里补上新文本的译文，否则会显示中文原文。
