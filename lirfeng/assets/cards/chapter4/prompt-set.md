# 第四关“梦幻森林”美术提示词记录

统一画风：深色奇幻卡牌插画，华丽高对比，梦幻夜森林、发光蘑菇、蓝紫月光与青色溪流；主体清晰居中，完整立绘构图，不包含文字、数字、卡框或水印。史莱姆角色以半透明凝胶质感、圆润轮廓和内部微光为共同视觉语言。

## 首领头像

20张独立方形头像依次表现：露珠幼母、苔光守望者、蓝泡采集者、荧蕈胶卫、月潭医师、藤蔓黏兽、紫晶分裂者、溪语祭司、沼光巨胶、菌伞吞食者、幻露巡游者、碧涡守门者、星斑软泥姬、古树融胶、翠晶凝视者、深潭回复师、月虹胶龙、千滴合生体、森心史莱姆领主，以及以用户提供的女性史莱姆法师为人物参考的碧露大贤者·涅芙莉。每张采用不同颜色、轮廓、饰品与森林环境元素，并保持同一系列的幽蓝发光边缘和卡牌肖像质感。

1. 滴露幼胶：黎明露珠中诞生的幼小蓝色史莱姆侦察兵。

4. 荧蕈投手：以发光蘑菇孢子为弹药的远程史莱姆。
5. 分裂先锋：正在一分为二、向前冲锋的紫蓝色史莱姆战士。
6. 月潭凝卫：在月潭前举起透明凝胶盾牌的高大哨卫。
7. 返生泥巨像：由森林泥土、根系与凝胶重组的巨大魔像。
8. 幻林胶质贤者：漂浮在符文与萤火之间的古老史莱姆贤者。
9. 苍翠吞噬者：吞纳藤蔓、果实与魔力后膨胀的巨型绿胶怪。
10. 沧澜史莱姆王：头戴水晶冠冕、统御小史莱姆的蓝色王者。
